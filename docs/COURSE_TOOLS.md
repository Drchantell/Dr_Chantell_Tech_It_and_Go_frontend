# Tech It & Go! — Course Tools and Skills

**Author:** Dr. Chantell McDowell  
**Program:** Per Scholas Software Engineering  
**Project:** Tech It & Go! Full-Stack Capstone

## Tools I Used Directly in Tech It & Go!

### Frontend
- HTML5 — page structure generated through React components
- CSS3 — responsive design, branding, layout, forms, cards, and mobile styles
- JavaScript (ES6+) — application logic, state, events, array methods, async/await, and modules
- React — reusable user-interface components
- React Router — page navigation and protected routes
- Vite — frontend development and production build tool
- Fetch API — communication with the Express API

### Backend and APIs
- Node.js — JavaScript runtime for the backend
- Express.js — server and API framework
- REST API design — GET, POST, PATCH, and DELETE routes
- Express middleware — JSON parsing, CORS, authentication, authorization, errors, and route protection
- dotenv — private environment-variable loading
- CORS — controls which frontend origins can call the API

### Database
- MongoDB Atlas — hosted NoSQL database
- Mongoose — schemas, models, validation, references, and database queries
- CRUD — Create, Read, Update, and Delete for equipment and lending requests

### Authentication and Security
- bcrypt — password hashing
- JSON Web Tokens (JWT) — authenticated sessions for protected API requests
- Role-based authorization — borrower and staff permissions
- Ownership checks — borrowers can access only their own lending requests

### Development, Testing, and Deployment
- VS Code — development environment
- Git — version control
- GitHub — repositories and project history
- Postman — API testing during development
- Supertest — automated API integration tests
- Node test runner — backend test execution
- GitHub Actions — automated frontend build and backend test checks
- Render — prepared backend deployment
- Vercel — prepared frontend deployment

## Other Course Concepts I Learned

I also learned concepts that I can explain even though I did not force every one of them into this MVP. Choosing the right tool for a project is part of software engineering.

- TypeScript — type safety and typed React/JavaScript development
- Document Object Model (DOM) — how browser pages are represented and updated
- GraphQL — flexible API queries compared with REST
- OAuth 2.0 — third-party authentication concepts
- Java and Spring Boot concepts — server-side application development
- SQL concepts — relational data and queries
- NoSQL concepts — document-based data design used directly with MongoDB
- Agile workflow — breaking work into manageable tasks and iterations
- Authentication and authorization — identity versus permissions
- Artificial Intelligence for Software Engineering — responsible use of AI in development and problem solving

## Why I Did Not Use Every Technology as a Runtime Dependency

A capstone should show good technical choices, not add tools just to make the list longer. Tech It & Go! is a JavaScript MERN-style application, so I kept the working MVP focused on React, Node.js, Express, MongoDB, REST, JWT, and the tools needed to test and deploy that stack.
